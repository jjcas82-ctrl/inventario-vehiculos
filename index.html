Servicio de reconocimiento de texto más preciso para leer el VIN del parabrisas. Es gratuito: regístrate en ocr.space/ocrapi, obtén tu API key gratis y pégala aquí. Requiere internet. Si lo dejas vacío, se usa el lector local del navegador.

Alertas de antigüedad

Define a partir de cuántos días sin movimiento una unidad se marca como por vencer (🟡) o estancada (🔴). Afecta el panel de inicio, la campana y el semáforo del inventario.

Catálogos (listas para autocompletar)

Define las listas que el personal elige al registrar una unidad (color, tipo, versión, transmisión). Mantienen la base limpia y sin errores de captura. Si alguien escribe un valor nuevo, se agrega aquí automáticamente.
